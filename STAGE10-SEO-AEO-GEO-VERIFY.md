# Этап 10 — SEO / AEO / GEO: sib-del.ru

Дата подготовки: 27.10.2026. Основа: архив SibDel от 27.10 с уже применёнными этапами «Активные сессии» и «Сотрудники».

## Что добавлено

- Продолжено серверное SEO-формирование: canonical / title / description / OG / Twitter-метатеги.
- JSON-LD, основанный **исключительно на данных реального каталога**: WebSite, OnlineStore (без выдуманных реквизитов), WebPage/ItemPage, Product/Offer, BreadcrumbList.
- Для товара: фактическая цена RUB, актуальное наличие, изображение только при наличии проверенного URL, подтверждённый рейтинг на основе одобренных отзывов. Если данных нет, свойство не добавляется.
- SEO категории (`/catalog.html?category=<slug>`) на основе активных категорий из PostgreSQL: уникальные заголовки, H1, description, canonical, BreadcrumbList. Некорректные/неактивные категории → 404; сложные фильтры остаются `noindex, follow`.
- `/sitemap-categories.xml` и ссылка в индексе `/sitemap.xml`. Новая FAQ-страница `/faq.html` включена в `sitemap-pages.xml` и связана из Footer.
- Шаблоны production `.env` и Nginx адаптированы к `sib-del.ru` (финальную установку Nginx проводить только после проверки текущей конфигурации и SSL).
- Скрипт `npm run seo:live-check -- https://sib-del.ru` для проверки уже опубликованного домена.

**Не добавлено сознательно:** ложные адреса, телефоны, ИНН, график, `LocalBusiness` без реальных реквизитов, выдуманные отзывы, фиктивные оценки, ссылки на несуществующие соцсети, необязательные `llms.txt`/`FAQPage` ради баллов.

## Установка без риска для базы

1. На компьютере клиента/разработчика в корне `SibDel` выполните `git remote -v`, `git branch --show-current`, `git status --short`. Ожидаемый origin: `Dimas-Shumil/SibDel`; ветка: `main`. Рабочие изменения не затирать.
2. Если патч этапа 9 ещё не установлен, сначала примените его и проверьте. Данный патч собран поверх этапа 9.
3. Распакуйте содержимое ZIP в **корень проекта** с заменой указанных файлов. В архиве нет `.env`, базы данных, миграций, `node_modules`, `.git`, каталога с пользовательскими фото и приватных ключей.
4. Проверьте: `node --test tests/seo-stage10.test.mjs` — 9 тестов без БД.
5. Проверьте: `npm run test:seo` (включает прежние интеграционные тесты с Express), `npm run test:staff-unit`, `git diff --check`. Для запуска интеграционных тестов требуются ранее установленные зависимости (`npm ci` в случае их отсутствия).
6. Запустите приложение обычным способом, откройте главную, `/catalog.html`, страницу категории, конкретный товар, `/faq.html`; просмотрите исходный HTML и метатеги в браузере. Проверьте мобильную версию FAQ.
7. Сравните `git diff --stat` и `git status --short`. Коммит делайте только после ручных проверок и подтверждения отсутствия конфликтов.

## Сервер / DNS / индексирование (только после готовности VPS)

- Убедитесь, что A-запись `sib-del.ru` ведёт на актуальный публичный IPv4 VPS; удалите старые или ложные записи, особенно AAAA при отсутствии IPv6.
- Настройте HTTPS-сертификат для `sib-del.ru` и `www.sib-del.ru`, если будете поддерживать `www`.
- `www.sib-del.ru` и HTTP должны **301** перенаправляться на `https://sib-del.ru/...`; НЕ копируйте шаблон Nginx поверх рабочего файла без проверки.
- В **приватном** production `.env` задайте `APP_URL=https://sib-del.ru` и `SEO_SITE_URL=https://sib-del.ru`. Локальный `.env` не менять ради теста: иначе canonical будет преждевременно публичным.
- После публикации проверьте `https://sib-del.ru/api/health`, `/robots.txt`, `/sitemap.xml`, `/sitemap-pages.xml`, `/sitemap-categories.xml`, `/faq.html`, один реальный товар и личный кабинет `noindex`.
- Запустите: `npm run seo:live-check -- https://sib-del.ru`.
- Подтвердите владение доменом через DNS в Яндекс Вебмастере и Google Search Console, добавьте Sitemap. При необходимости используйте Google Merchant Center для товаров.
- Проверяйте внешними сервисами **после деплоя**: PageSpeed Insights/Core Web Vitals, Rich Results Test, Google Search Console, Яндекс Вебмастер.

## Открытые задачи / блокирующие данные от заказчика

1. В предоставленном ZIP **нет папки `site/images/`**. Серверный проект ожидает `/site/images/...` на главной, в каталоге и др. Нужно восстановить из исходного репозитория/рабочей машины, проверить реальное отображение и оптимизацию WebP.
2. В `public/contacts.html` указано, что контактные и юридические сведения **не подтверждены**. Перед реальным SEO-продвижением получить у продавца название организации/ИП, контактные данные, адреса и фактические часы, актуальные зоны доставки. После подтверждения настроить LocalBusiness с достоверными данными.
3. Юридические документы в Footer помечены как проекты — привести в окончательный вид и согласовать до полноценного запуска магазина.
4. Неизвестны авторитетные соцсети и оригинальные отзывы, поэтому `sameAs` и дополнительные рейтинги не публиковались.
5. Не проводились замеры скорости Lighthouse и оценка «100/100»: публичный домен пока не был доступен для успешного аудита. Техническая подготовка не гарантирует индексирование или позиции.
6. После запуска необходимо наполнять страницы оригинальными описаниями реальных товаров, качественными изображениями и правдивой информацией о доставке — автоматическая генерация одинаковых SEO-текстов не заменяет продвижения.
